# Scope: reproduction field of view

## Scoped Repository

Only issues and pull requests in the course's Path Review repository are targeted:

- Repo: `codepath/pathreview-ai301-fa26-s1`

## Path Review House Rules for Unit 2

1. **Claiming is promising, not asserting**: Claim comments must state intent to investigate and reproduce, name the environment/steps you plan to test, and promise a reproduction report. Do not assert a fix before reproducing.
2. **Independent claims**: Other students' claim comments do not block you. Claim anyway; course credit attaches to your posted work, not being first.
3. **No piggybacking**: Never post generic "+1 same issue" or "can confirm". Every reproduction comment must contain your own full environment specifications, reproduction commands, and observed outputs.
4. **Honest reporting**: An evidenced "cannot reproduce" report earns full marks when executed faithfully with complete environment details.
