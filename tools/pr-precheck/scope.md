# Scope: pull request field of view

## Scoped Repository

Only pull requests targeted at the course's Path Review repository are scoped:

- Repo: `codepath/pathreview-ai301-fa26-s1`

## House Rules for Unit 4

1. **Pull requests are opened from your fork**: PRs must be opened from your fork's feature branch (`fix/<issue-number>-<slug>`) against `codepath/pathreview-ai301-fa26-s1:main`.
2. **Working notes stay out of the PR**: `plan.md`, draft notes, and temporary test artifacts must NOT be committed to the PR branch.
3. **AI Disclosure**: All PR descriptions must include an explicit AI-use disclosure statement in your own words.
