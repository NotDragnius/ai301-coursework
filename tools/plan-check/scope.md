# Scope: planning field of view

## Scoped Repository

Only issues and pull requests in the course's Path Review repository are targeted:

- Repo: `codepath/pathreview-ai301-fa26-s1`

## Path Review House Rules for Unit 3

1. **Plan comments are proposals**: Plan comments state your diagnosis, scope pair (in and not-in), targeted files, proposed approach, and expected test outcomes. Do not assert completion before building.
2. **Independent planning**: A classmate's plan comment does not block yours. Post your own plan anyway; credit attaches to the PR you open in Unit 4.
3. **Branch naming convention**: Create a dedicated git branch in your fork named `fix/<issue-number>-<slug>` (e.g. `fix/69-json-array-fallback`).
4. **Plan document location**: `plan.md` lives in your course repository (`beat-1-sandbox/unit-3/plan.md`), never on your code branch.
